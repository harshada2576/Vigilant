**Date:** 2026-11-09  
**Scope:** local frontend, Matrix bridge integration, Docker/Synapse startup, registration and login

- Registered a new Matrix account through the browser UI.

- Confirmed both flows reached the authenticated dashboard.

## Still remaining

- The full Compose stack does not start because the legacy `minio/minio:latest` image reference is no longer pullable. Postgres and Synapse are sufficient for the verified auth flow, but media object storage needs a supported pinned image or an intentional local-filesystem configuration.
- Sync status remains `unknown`; bridge 0.1.5 has no sync lifecycle or error callbacks.
- User profile lookup and room member enumeration are not exported by the bridge.
- Directory search and presence remain authenticated direct Matrix HTTP calls.
- Stable Matrix event IDs, callback unregister/dispose, upload progress, and `mxc://` avatar resolution remain unavailable.
- Typing and read receipts are wired but still need multi-user browser verification.
- External production Synapse deployment and federation were not tested.
